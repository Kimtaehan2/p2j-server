# AI 실험

담당: 박영준.

프롬프트 프로토타입, STT 정확도 비교(클로바 vs Google), 한국어 발화 표본 정리를 여기서 한다.
**이 폴더의 코드는 서버에 포함되지 않는다.** (앱은 `app/` 만 import 하고, ruff·mypy·pytest 대상에서도 제외된다)

백엔드가 Python(FastAPI)이므로 **여기서 검증한 코드를 그대로 `app/services/ai/` 로 옮기면 된다.** 언어 변환이 없다.

## 규칙

- 실제 API 키를 파일에 적지 않는다. 환경변수로 읽는다.
- 음성 표본에 개인정보가 섞이면 커밋하지 않는다.
- 운영에 쓸 프롬프트가 정해지면 `app/services/ai/` 으로 옮기고 리뷰를 받는다.
- 노트북(`.ipynb`)이나 임시 스크립트를 두어도 된다. 정리 책임은 작성자에게 있다.

## 기록할 것

최종보고서에 "한국어 목표 발화 표본으로 정확도를 확인했다"고 쓰려면 근거가 필요하다.

- 입력 발화 / 기대 출력 / 실제 출력
- `status` 분포 (`ok` / `partial` / `fallback`)
- 실패 사례와 원인
